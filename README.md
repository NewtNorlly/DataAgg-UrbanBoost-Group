## 🎯 项目概述

本研究以 **武汉华安里 1km² 微型老旧街区** 为对象，基于计算城市科学、视觉城市主义、时间地理学、环境心理学等理论基础，构建 **「时间沉积」感知框架** —— 将一切指标统一视为"时间在空间中的当前沉积状态"。

### 🌟 核心创新

> 横轴空间语法解释要素共现，纵轴时间印记解释这些共现的历时厚度。  
> 两者不可拆解，共同构成该点位的 **"时间沉积值"**。

<div align="center">

| 研究维度 | 内容 |
|:---:|:---|
| 🧠 **理论基础** | 空间句法 · CPTED · 破窗理论 · 城市针灸 · 场所依恋 |
| 📸 **数据来源** | 97张华安里街景图像 → AI语义识别 → 30维文本描述 |
| 🤖 **感知模型** | BERT多语言情感分类 → 5星评分 → 0-1感知得分 |
| ⚖️ **评分框架** | 6项实体空间维度 + 1项针灸式更新潜力维度 |
| 🗺️ **最终输出** | 94个点位的感知得分（含GPS），可直接导入ArcGIS |

</div>

## 🔄 数据处理流程

### Step 1: 数据读取
- 从 `华安里_分析结果.xlsx` 读取 97 条记录
- 每条包含：编号 · GPS坐标 · 原文件名 · AI文本JSON（30维）

### Step 2: JSON解析
- 成功解析：**94条** ✅
- 解析失败：**3条** ⚠️（ID=22, 50, 97，JSON截断）

### Step 3: BERT情感评分
- 模型：`nlptown/bert-base-multilingual-uncased-sentiment`
- 输出：1-5星 → 映射为 0.00 / 0.25 / 0.50 / 0.75 / 1.00
- 总计：94条 × 30维 = **2,820次推理**
- 运行环境：CPU，耗时约 **25分钟**

### Step 4: 维度映射 + 加权
- 30个AI子维度 → 7个框架维度
- 负向指标自动反转
- 维度内取均值，维度间贝叶斯权重加权
- 维度7（针灸式更新潜力）= 1 − mean(前6维度)

### Step 5: 结果输出
- CSV · Excel · JSON 三种格式
- 包含GPS坐标，可直接导入ArcGIS制作热力图

## 🚀 使用方法

### 环境要求

```bash
Python 3.11+
transformers  torch  openpyxl  pandas
```

### 一键运行

```bash
# 1. 创建虚拟环境
uv venv
uv pip install transformers torch openpyxl pandas

# 2. 运行脚本
python 华安里_BERT感知评分脚本.py
```

### 输出格式

| 字段 | 说明 |
|:---|:---|
| `编号` | 数据序号 |

## 📝 方法说明与局限

### ✅ 方法优势

- **全链路自动化**：AI文本描述 → BERT评分 → 加权计算，无人工干预
- **理论锚定**：每个子维度有明确的理论支撑（CPTED、空间句法等）
- **可复现**：完整脚本，一键运行
- **GIS友好**：直接输出带坐标的得分表

### ⚠️ 已知局限

| 问题 | 影响 | 解决方案 |
|:---|:---|:---|
| 3条数据JSON截断 | 缺失3个点位 | 联系组长补数据 |
| BERT 5星评分粒度较粗 | 区分度有限（5档） | 后续可换用回归模型 |
| 维度7（针灸式更新潜力）为代理值 | 未结合TTI计算 | 任务3/4接入TTI后更新 |
| 中文文本BERT适配 | 英文为主的多语言模型 | 后续可换用中文优化模型 |

### 🔮 后续改进方向

1. **模型升级**：替换为中文优化的情感分析模型（如 `uer/roberta-base-finetuned-jd-binary-chinese`）
2. **TTI接入**：结合时空厚度指数（TTI2.0），升级维度7为真正的针灸穴位识别
3. **细粒度评分**：使用回归模型替代分类模型，输出连续0-1分数
4. **不确定性量化**：利用贝叶斯框架输出每个得分点的置信区间
